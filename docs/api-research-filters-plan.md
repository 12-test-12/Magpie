# API 研究筛选与请求样本对照实施方案

日期：2026-10-20。基线：`2c428e7`，0.29.0 / schema v19。开发分支：`codex/api-research-filters`。

## 1. 用户范围与目标

用户要求先编写 Markdown 方案，再完成第一部分 API 研究功能。实现参数名/位置、已观察响应状态与 MIME、来源性质、凭据线索筛选，以及同一接口两份请求样本的摘要对照。报告、Finding 表单改造、JS 解析扩展、Notes/任务扩展及 Agent 不在本批范围。

本批只读取现有 Entity、Observation、Evidence、Contribution。保持原生解析、身份、归一化、历史事实、Undo/Redo 和人工工作层写入契约。不增加事实库、数据库迁移、网络请求或自动漏洞判定。现有暂存复验截图和未跟踪 Agent 方案保留，不纳入本批提交；不合并、不推送。

## 2. 查询口径

| 查询项 | 口径 |
|---|---|
| `parameter_name` | 精确、区分大小写的参数名，不把 `%`/`_` 当通配符；可与位置组合 |
| `parameter_location` | query/body/path/header/cookie/unknown；单独设置时筛选含该位置参数的对象 |
| `response_status` | 100–599 的整数；必须有对应 HTTP 请求样本，不根据独立状态观测拼造请求 |
| `response_mime` | 精确 MIME 类型；忽略大小写及 `;charset=…`，不推断缺失 MIME |
| `credential` | cookie/bearer/basic/api_key/other/unknown/no_recognized_credentials_observed；逐样本使用已有类别，不把缺字段解释为无凭据 |
| `api_origin` | http_sample（有有效请求样本）、js_only（有 JS 静态来源且无请求样本）、declaration_only（有契约声明且无请求样本/JS 静态来源）；全部表示不限制，多来源允许共存 |

响应状态、MIME、凭据或“有 HTTP 请求样本”条件必须在**同一份样本**成立，禁止把请求 A 的 200 与请求 B 的 Bearer 拼成命中。同时设置方法或参数筛选时，也必须由这份样本命中；不能用 JS 中的参数名冒充已观察请求的参数。现有样本可直接验证 query/body/header 名称，不能凭其他观测补造 path/cookie 参数。没有样本约束时，参数查询可使用既有参数位置观测、JS 静态查询参数名及请求样本。

只查询当前项目有效、未合并对象及有效观测；损坏 JSON、缺字段、未知版本不作为有效样本，也不能据此归为无样本的仅 JS/仅声明对象，保留在未限制来源的列表与原有详情中。旧身份与未知数据保留。筛选不命中只表示现有记录不满足，不证明目标不存在该特征。缺少凭据不代表无鉴权或漏洞。

新增条件仅用于 API 分类，其他分类收到非空条件时显式拒绝。条件进入游标签名；主机/路径聚合、列表和总数共用同一谓词。空条件兼容既有查询。

## 3. 前端与样本对照

- API 页面增加独立研究筛选区，沿用应用/重置、下钻、返回、翻页、项目切换和会话内导航记忆；不把筛选应用到其他分类。
- 研究筛选区可展开/收起，应用后自动收起并显示已应用条件摘要，保证窄桌面仍有可操作的结果区域。
- 请求样本页允许选择同一接口的两份样本，跨样本分页保留最多两份副本；切换接口/项目时清空。
- 对照请求时间、状态码、MIME、响应大小、参数名、请求头名和凭据类别，显示相同/变化。显示样本 ID、record path、内容截断/未知提示及各自证据入口。
- 仅比较已保存的脱敏摘要，不读取/展示请求体、头部或凭据原值，不声称参数值、响应正文或权限行为一致；无时间不推断先后。

## 5. 验收场景

1. 参数名/位置、状态、MIME、来源和凭据分别及组合命中；缺失、损坏、截断和未知数据如实显示；`%`/`_` 为字面字符。
2. 同接口 A=200/Cookie、B=401/Bearer：200+Bearer 不命中；401+Bearer 命中。参数也不跨样本拼接。
3. 有样本、仅 JS、仅声明、多来源、旧身份、空项目和跨项目隔离；撤销/复原后随有效贡献变化。
4. 分组计数与列表一致；全部分页无漏重；改变任一筛选后旧游标拒绝。
5. 前端应用/重置、分类切换、返回保留和迟到响应；两份样本跨页选择、对照、移除及切换对象清空。
6. 用 `dev.py` 新命名合成库实际浏览器操作筛选、下钻、翻页、样本对照、证据打开与窄桌面；保存真实截图与结果。禁止用真实项目做测试。
7. 完成 `check.py`、前端测试、构建、OpenAPI 与源文件差异检查。实际解释器如为 Python 3.12.4 则如实登记，不冒称 3.13 或严格性能基准已验证。
